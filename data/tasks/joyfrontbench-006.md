二级分类：静态 SVG 插画/场景

请用 **SVG** 绘制一幅**静态**矢量插画场景。最终交付一个**完整、可直接运行的单 HTML 文件**（可保存为 `.html` 双击在浏览器打开，无需后端、无需联网、无需任何构建工具或外部资源）。

### 画面情境

**黄昏，一只优雅的暹罗猫独自坐在高层公寓的窗台上，享受城市傍晚的宁静。**

- 时间是日落时分，天空从地平线的暖橙金色向高空的靛蓝紫色过渡，几缕薄云被夕阳染上暖边，零星星点开始浮现。
- 猫端坐在室内一侧的宽木质窗台上，**面向观众、微微侧头望向窗外**，蓝眼睛在暖光下格外清亮；它的长尾沿窗台边缘优雅垂落。
- 窗台一角摆着一小盆绿植，窗框把画面自然地"框"住一部分，强调"从室内向外眺望"的纵深感。
- 窗外是壮观的**曼哈顿天际线**：高低错落的摩天楼群在暮色中变成偏冷的剪影，成百上千扇窗户次第亮起暖黄的灯，近处楼体清晰、远处楼群隐入暮霭（空气透视）。夕阳的余晖在楼群缝隙间洒下最后一道暖光。
- 整体氛围：温暖、静谧、有电影感的城市黄昏，猫是画面的情感焦点，城市是壮阔的背景。

所有图形**一律用 SVG 矢量元素绘制**（`path` / `circle` / `ellipse` / `rect` / `polygon` / `g` / `linearGradient` / `filter` 等）。**不允许引用任何外部图片、位图或字体文件**。画面为**纯视觉插画**：不要 HUD、侧边栏、文字标签或任何 UI 控件。

### 一、画面内容与构图

画面通过**前景 / 中景 / 远景**构建空间层次：

1. **前景 · 暹罗猫（主体插画，画面焦点）**
   - 一只可清晰辨识的**暹罗猫**，采用自然的**坐姿**，面向观众、微侧头，作为画面视觉焦点。
   - 必须体现暹罗猫的品种特征：**浅色（米白/奶油）身体 + 深色重点色（face mask 面部、耳朵、四肢末端、尾巴呈深褐/深灰）对比**、**一对蓝色的杏仁形眼睛**、纤细优雅的体型、直立的大三角耳。
   - 比例解剖合理、左右协调，各部件连接自然、不失真、不畸变、不穿模。
   - 猫应**稳稳坐在窗台上、有真实的接触感与投影**，不能悬浮在空中。

2. **中景 · 窗台 / 窗框**
   - 猫所坐的木质窗台、一侧的窗框与角落的小盆栽，作为前景与远景之间的过渡层，强调"从室内向外眺望"的纵深与"框景"感。

3. **远景 · 纽约天际线（场景图）**
   - 层次丰富的**曼哈顿天际线**：高低错落的摩天楼群，具备可辨识的城市意象（可含类似帝国大厦尖顶、克莱斯勒大厦、方形玻璃幕墙塔楼、水塔等元素）。
   - 建筑要有**纵深层次**（近处楼体细节多、远处楼体简化并隐入暮霭，体现空气透视）。
   - 建筑细节丰富：窗格、次第亮起的暖黄窗灯、楼顶结构等，展现出乎意料的细节与美感。

### 二、视觉布局与空间层次要求

1. **构图**：设置合理的 `viewBox`，前/中/远景层次分明，主体（猫）位置与大小得当，视觉引导清晰、留白舒适。
2. **空间纵深**：通过遮挡关系、近大远小、近实远虚（空气透视）表现景深，天际线不能是平铺的等大剪影。
3. **自适应**：改变窗口尺寸时画面自适应缩放且保持宽高比、不变形。

### 三、图形结构表达要求

1. 使用 `<g>` 对「猫」「窗台/中景」「天际线」「天空/背景」等分层分组，各主要部件（如猫的头/耳/身/尾/眼、各栋建筑）作为可独立引用/变换的子结构，组织有条理、命名清晰。
2. 主体与场景的构成元素完整、可辨识，层级关系正确（前景遮挡中景、中景遮挡远景）。

### 四、细粒度样式与氛围要求

1. **光影氛围**：设定统一的光线氛围（如黄昏暖调 / 蓝调夜景 / 清晨冷光其一），画面整体光影一致。运用**渐变**（`linearGradient` / `radialGradient`）表现天空过渡、建筑受光/背光、猫毛的重点色渐变等。
2. **质感细节**：合理运用描边、阴影/滤镜（如 `feGaussianBlur` 做柔光/雾气）、透明度表现玻璃反光、窗灯辉光、猫的投影等细节。
3. **配色**：整体配色和谐、有设计感与美感，色调统一，避免生硬的纯色堆砌。

### 五、技术与交付约束

1. 交付**单个 HTML 文件**，SVG 与样式全部内联其中，可直接双击运行，不依赖任何外部资源、网络或构建工具。
2. 全部图形为 SVG 矢量绘制，不引用外部图片、位图或字体文件。
3. 纯视觉插画，无 HUD / 侧边栏 / 文字 / UI 控件。
