一级分类：SVG / 矢量图形生成
二级分类：SVG 动画

请使用 HTML、CSS 和原生 SVG，生成一幅具有医学科普插图质感的“人体血液循环动态示意图”。

最终结果必须是一个能够直接在现代浏览器中运行的单文件 HTML。页面加载后自动播放动画，不需要、也不得依赖用户交互。

一、整体画面

1. 使用 SVG 绘制简化但结构清晰的人体正面轮廓。
2. 建议画布比例为 1200 × 900，也可以使用等比例 viewBox 实现响应式显示。
3. 画面应包含：
   - 心脏
   - 左右肺
   - 头部
   - 肝脏
   - 左右肾脏
   - 上肢或上半身组织
   - 下肢
4. 所有重要器官和血管均需使用清晰的中文文字标注。
5. 人体正面图中的左右方向应遵循解剖学方向，即人体左侧位于观察者右侧。
6. 画面应同时兼顾医学示意性和视觉美观，不能只是简单的红蓝线条拼接。
7. 应通过透明度、渐变、描边宽度和前后遮挡表现器官及血管的空间层级。

二、心脏结构

1. 心脏必须位于胸腔中央略偏人体左侧。
2. 心脏内部必须清晰区分并标注：
   - 右心房
   - 右心室
   - 左心房
   - 左心室
3. 必须表现以下四个瓣膜的位置或状态：
   - 三尖瓣
   - 肺动脉瓣
   - 二尖瓣
   - 主动脉瓣
4. 心房、心室和瓣膜应当作为可独立控制动画的 SVG 元素组织，不能将整个心脏合并成一个只能统一缩放的图形。
5. 左右心房需要基本同步收缩。
6. 左右心室需要基本同步收缩，但必须晚于心房开始收缩。

三、主要血管

必须绘制、连接并标注以下血管：

- 主动脉及主动脉弓
- 上腔静脉
- 下腔静脉
- 左右肺动脉
- 左右肺静脉
- 通向头部的动脉和回流静脉
- 通向肝脏的动脉和回流静脉
- 通向左右肾脏的动脉和回流静脉
- 通向下肢的主要动脉和回流静脉

血管必须形成连续的循环网络，不能由互不连接的装饰性路径组成。

至少表现三处血管的分叉、汇合或前后穿插关系。血管交叉时必须通过遮挡、描边或局部间隔清楚表达前后层级，避免产生错误的连通关系。

四、血液循环路径

必须准确表现肺循环和体循环。

肺循环顺序：

右心室
→ 肺动脉瓣
→ 肺动脉
→ 左右肺部毛细血管
→ 肺静脉
→ 左心房

体循环顺序：

左心室
→ 主动脉瓣
→ 主动脉
→ 头部、肝脏、肾脏及下肢等身体组织
→ 上腔静脉和下腔静脉
→ 右心房

必须保证：

1. 右心室只向肺动脉射出缺氧血。
2. 左心室只向主动脉射出含氧血。
3. 肺动脉表现为缺氧血。
4. 肺静脉表现为含氧血。
5. 含氧血和缺氧血的颜色转换发生在肺部毛细血管区域。
6. 含氧血在身体组织处释放氧后，应逐渐转换为缺氧血。
7. 所有血流方向必须正确，不得出现逆流。
8. 肺循环和体循环必须首尾连续，能够从任意心腔沿血流方向追踪一整个循环。

五、颜色与视觉规范

1. 含氧血使用明亮的红色系。
2. 缺氧血使用深蓝或蓝紫色系。
3. 动脉和静脉不能全部使用单一纯色，必须使用 SVG 线性渐变或径向渐变表现血管的立体感和流动感。
4. 肺部毛细血管区域应呈现从蓝色逐渐过渡到红色的视觉效果。
5. 身体组织的毛细血管区域应呈现从红色逐渐过渡到蓝色的视觉效果。
6. 血管内部的血流粒子应与血管颜色保持一致，同时具有适当的高光或发光效果。
7. 背景、器官和文字的色彩需要保证足够对比度。
8. 页面中必须包含：
   - “人体血液循环动态示意图”标题
   - 含氧血图例
   - 缺氧血图例
   - 血流方向图例
   - 肺循环说明
   - 体循环说明

六、动态血流

1. 使用多个粒子沿血管的实际曲线路径运动，表现连续血流。
2. 粒子必须沿 SVG path 运动，不得只使用水平或垂直直线位移冒充血流。
3. 血管绘制路径与粒子运动路径应尽量复用同一份几何数据，避免粒子偏离血管中心。
4. 粒子进入血管分支时需要合理分流，并在静脉侧重新汇合。
5. 不同路径上的粒子动画需要错峰开始，不能所有粒子同时出现或同时到达。
6. 粒子密度和运动速度应保持视觉连续性。
7. 动画循环连接处不得出现明显跳帧、倒退、瞬间传送或长时间空白。
8. 静脉回流可以持续进行，但从心室进入主动脉和肺动脉的粒子应具有明显的周期性射血节奏。
9. 主动脉和肺动脉中的粒子应在对应心室射血阶段出现并短暂加速。
10. 禁止在心室舒张期持续从主动脉或肺动脉大量产生新的射血粒子。

七、符合生理规律的心动周期

以静息心率约 75 次/分钟为基准，一个完整心动周期设为约 0.8 秒。

为了便于观察，可以将整个周期等比例慢放至 1.6 秒或 2.4 秒，但以下阶段顺序和时间比例必须保持不变。

阶段一：舒张与被动充盈，周期的 0%–50%

- 左右心房和左右心室均处于舒张状态。
- 上、下腔静脉中的缺氧血进入右心房。
- 肺静脉中的含氧血进入左心房。
- 血液通过开放的三尖瓣和二尖瓣进入心室。
- 肺动脉瓣和主动脉瓣处于关闭状态。
- 心室轮廓应表现为逐渐充盈，而不是收缩。
- 这一阶段不得从心室持续进行主动射血。

阶段二：心房收缩，周期的 50%–62.5%

- 左右心房先于心室收缩。
- 心房轮廓轻微向内形变，将剩余血液推入心室。
- 三尖瓣和二尖瓣保持开放。
- 肺动脉瓣和主动脉瓣保持关闭。
- 左右心室仍处于舒张或充盈末期，不得与心房同时开始收缩。

阶段三：心室等容收缩，周期的 62.5%–70%

- 左右心室开始同步收缩。
- 三尖瓣和二尖瓣关闭，阻止血液倒流回心房。
- 肺动脉瓣和主动脉瓣尚未开放。
- 此阶段心室轮廓可以开始向内收缩，但不得出现大量射血粒子。
- 四个瓣膜在短时间内均处于关闭状态。

阶段四：心室射血，周期的 70%–95%

- 肺动脉瓣和主动脉瓣开放。
- 右心室将缺氧血射入肺动脉。
- 左心室将含氧血射入主动脉。
- 主动脉和肺动脉中的血流粒子在此阶段集中出现并加速。
- 三尖瓣和二尖瓣保持关闭。
- 心房此时处于舒张状态，并继续接收静脉回流。
- 心室应表现为由充盈状态向收缩状态平滑形变。

阶段五：心室舒张与周期复位，周期的 95%–100%

- 左右心室停止收缩并开始舒张。
- 肺动脉瓣和主动脉瓣关闭，防止血液倒流。
- 主动脉和肺动脉停止产生新的射血粒子。
- 心室压力下降后，为下一周期的房室瓣开放和被动充盈做好准备。
- 动画应平滑进入下一周期，不得突然恢复初始形状。

八、心脏动画限制

1. 禁止仅对整个心脏应用统一的 scale 动画模拟心跳。
2. 心房与心室必须拥有不同的动画时间轴。
3. 心房必须先收缩，心室必须后收缩。
4. 收缩应主要表现为心腔边界向内形变，而不是心脏整体等比例缩小。
5. 心脏外轮廓允许有轻微缩放、位移或形变，但不能代替四个心腔的独立运动。
6. 心脏动画、瓣膜状态和血流粒子必须使用同一个周期基准同步。
7. 粒子不得穿过处于关闭状态的瓣膜。
8. 不得出现血液从心室倒流回心房的动画。
9. 动画应使用缓动函数模拟肌肉逐渐收缩和舒张，避免机械式匀速缩放。
10. 整个动画必须无限循环，且循环衔接自然。

九、技术要求

1. 最终输出一个完整、可运行的 HTML 文件。
2. 只能使用：
   - HTML
   - CSS
   - 原生 SVG
   - 必要的原生 JavaScript
3. 禁止使用：
   - Canvas
   - WebGL
   - 外部图片
   - GIF 或视频
   - 第三方 JavaScript 库
   - 第三方 SVG 图标库
   - 外部字体或其他网络资源
4. 所有视觉主体必须由 SVG 元素绘制。
5. 应合理使用以下 SVG 能力：
   - path
   - linearGradient 或 radialGradient
   - mask 或 clipPath
   - filter
   - marker
   - symbol 与 use
6. 重复粒子、箭头或标记应尽量通过 symbol、use 或程序化生成复用。
7. 禁止通过逐帧硬编码大量坐标模拟动画。
8. SVG 中的 ID 必须唯一。
9. 重要元素应使用具有语义的 ID 或 class，例如：
   - left-atrium
   - right-atrium
   - left-ventricle
   - right-ventricle
   - aorta
   - pulmonary-artery
   - pulmonary-vein
   - superior-vena-cava
   - inferior-vena-cava
10. 页面应在无网络环境下正常运行。
11. SVG 不得出现关键内容裁切、文字重叠或粒子运动到血管外部的问题。
12. 在常见桌面浏览器中，动画应保持流畅。
