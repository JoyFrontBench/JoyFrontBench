一级分类：SVG / 矢量图形生成
二级分类：参数化SVG生成器

请你扮演一名资深视觉设计师和创意前端工程师，使用纯 SVG 为虚构城市艺术节 **NEON HARBOR 2027 / 城市声音与数字艺术节** 制作一个参数化活动海报生成器。它不是普通表单，也不是静态海报图片，而是可编辑、可换主题、可换尺寸、可导出 SVG/PNG/参数 JSON 的离线设计工具。

交付一个完整、可直接运行的 **单 HTML 文件**。保存后可离线打开，无需后端、联网、构建工具、远程字体、外部图片、外部 SVG、在线纹理或 3D 模型。海报主视觉、Logo、二维码占位、纹理和装饰必须全部由内联 SVG 原生元素生成，不得把预生成位图放进 SVG 冒充矢量设计。

固定活动信息：

- 英文标题：NEON HARBOR 2027
- 中文副标题：城市声音与数字艺术节
- 日期：2027.09.18–09.20
- 地点：海港工业艺术中心 · 上海
- 标语：城市在发声，像素正在呼吸
- 内容：LIVE / INSTALLATION / WORKSHOP / NIGHT WALK
- 开放时间：10:00–22:30
- 票务：Early Bird ¥199
- 入口文字：REGISTER / BUY TICKETS

## 一、产品结构

页面必须包含：

1. 控制面板：文本、颜色、主题、尺寸、密度、seed、网格/安全区、重置、导入导出。
2. 海报预览区：真实 SVG 预览，支持等比缩放。
3. 尺寸与安全区信息：当前规格、viewBox、导出比例、安全区提示。
4. SVG 结构/参数摘要：当前主题、尺寸、seed、密度、主要分组和资源 ID。
5. 导出区域：下载 SVG、复制 SVG、导出/导入参数 JSON、导出 PNG。

桌面端控制面板在侧边，海报预览为主区域；360px 下控制面板可折叠或分段，但主题、尺寸、文本编辑和导出必须仍可访问。

## 二、海报信息完整性

每个尺寸版本都必须包含并保持可读：英文标题、中文副标题、日期、地点、标语、内容列表、开放时间、票务信息、原创活动图形标、主视觉、SVG 二维码占位图形、入口文字。

切换尺寸时可以重新分组、缩写或调整字号，但不得丢失关键信息。长标题输入时不得直接溢出或遮挡全部信息，应通过换行、缩小字号或明确溢出提示处理。

## 三、主视觉方向

主视觉概念为“港口声波 + 城市网格 + 像素呼吸”，至少组合以下三种语义：

- 海浪或声波；
- 城市建筑网格；
- 港口坐标或航线；
- 发光像素节点；
- 抽象字母 N/H；
- 日夜交替节奏。

要求：

1. 主视觉原创且成为海报视觉焦点，不能只是随机圆形和模糊渐变光球。
2. 图形有明确生成规则，例如网格、节奏、波形、航线、节点密度。
3. 视觉复杂度由 density 和 seed 控制，任何密度下不得完全遮挡文字。
4. 相同参数和 seed 生成同一图形；“重新生成”可以改变 seed。

## 四、SVG 结构

合理使用多数 SVG 能力：path、rect、circle、line/polyline、polygon、text、linearGradient/radialGradient、pattern、clipPath、mask、filter、g 分组和 transform。

要求：

1. 使用 `<g>` 清晰分组：background、visual、title、event-info、ticket、qr、decorations、safe-area/grid。
2. SVG 有当前尺寸对应的 viewBox。
3. 文字、图形、滤镜、渐变、mask、clipPath 的 ID 唯一。
4. 禁止外部 `<image>`、远程字体和外部纹理。
5. 不得把整张海报变成一条不可理解的超长 path；结构应可读可维护。
6. 滤镜克制，不能导致正文模糊或性能明显下降。

## 五、主题与真正重排

至少提供三种版式主题：

1. **Geometric Pulse**：大型几何主视觉、强对角线/分区、标题尺度对比明显、数字艺术和音乐节气质。
2. **Swiss Grid**：明确列网格和基线、左对齐或网格化排版、克制色彩、信息层级清晰。
3. **Night Signal**：深色夜间版本，使用节点、声波和港口信号语言，小字对比度清晰，辉光不过度。

切换主题后必须同步更新构图、字体尺度、配色、主视觉参数和装饰方式，而不是只改背景色。

至少支持四种输出尺寸：

- A3 Portrait：3508 × 4961 比例；
- Social Post：1080 × 1350；
- Story：1080 × 1920；
- Landscape Screen：1920 × 1080。

要求：

1. SVG viewBox 与当前尺寸比例一致。
2. 切换尺寸后元素真正重排，不得只整体缩放或裁切同一竖版设计。
3. A3 竖版保留打印安全区；Story 版保留顶部/底部安全区；Landscape 版信息与主视觉左右分置；Social Post 缩略图下标题仍醒目。
4. 文字不溢出 viewBox，二维码和票务信息保持可见。

## 六、可编辑参数与确定性

控制面板至少允许修改：英文标题、中文副标题、日期、地点、标语、票价、主色、辅助色、背景色、主题、输出尺寸、主视觉密度、主视觉 seed、是否显示安全区、是否显示网格。

要求：

1. 修改文本、颜色、主题、尺寸、密度、seed 后 SVG 立即更新。
2. 密度和 seed 只影响生成式主视觉，不改变活动文字内容。
3. 不允许直接使用不可复现的 `Math.random()` 产生布局；必须通过 seed 构建确定性伪随机函数。
4. 相同参数和 seed 刷新后恢复同一海报。
5. 导出参数 JSON 后再导入，可恢复主题、尺寸、文本、颜色、density、seed 和主视觉。

## 七、排版和视觉约束

1. 建立明确的标题、副标题、日期地点、内容列表、票务和辅助信息层级。
2. 同一海报主色不超过 4 种，特殊强调色除外。
3. 正文与背景保持清晰对比；中文与英文混排对齐合理。
4. 不使用无法离线加载的字体，可用系统字体组合，通过字号、字重、字距和布局建立设计感。
5. 文字不能与主视觉无规则重叠。
6. 网格和安全区仅用于编辑预览，默认不进入最终导出。
7. 整体完成度应接近真实活动宣传海报，不像普通后台表单或随机 AI 风装饰。

## 八、导出与导入

必须支持：

1. 下载当前 SVG；
2. 复制当前 SVG 源码；
3. 导出当前参数 JSON；
4. 导入参数 JSON；
5. 导出 PNG。

要求：

- SVG 导出内容与当前主题、尺寸、文本、配色、seed、density 一致。
- 导出 SVG 可独立打开，不依赖当前 HTML 中的外部 CSS 或远程资源。
- 编辑网格、安全区、控制点和页面 UI 不得进入最终导出，除非用户显式选择包含安全区预览。
- PNG 导出比例与当前输出规格一致；如实际像素使用 1×/0.5×，需明确标注。
- 导入非法 JSON 时显示错误，不破坏当前海报。
- 不得依赖预先提供的参数文件；你必须通过“导出当前参数 JSON → 导入同一文件”验证恢复，非法 JSON 也由实现或测试代码自行构造。

## 九、响应式与可访问性

1. 360px 下可切换主题/尺寸、修改文本、调整 seed/density、导出 SVG/JSON。
2. 海报预览等比缩放，不导致页面整体横向溢出。
3. 所有输入控件有 label，按钮有可见 hover/active/focus/disabled 状态。
4. 主题、尺寸、网格和安全区开关有明确选中状态。
5. 错误提示和选中状态不能只靠颜色表达。
6. reduced-motion 下减少主题切换和预览动画，但内容不缺失。
