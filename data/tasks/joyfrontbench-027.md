一级分类：应用
二级分类：图像编辑应用

请你扮演一名资深图像工具前端工程师，擅长 Canvas 2D、图片解码、坐标变换、裁切、像素处理、矢量标注、图层管理、撤销重做、IndexedDB 持久化和浏览器本地文件导出。请实现一个完全本地运行的 **照片编辑与标注工作台**：用户导入 PNG/JPEG/WebP，完成裁切、旋转、翻转、全局调整、局部马赛克、矩形/箭头/文字/画笔标注、图层管理、前后对比、工程保存恢复和导出。

交付形式为 **Vite + React + TypeScript 多文件工程**。它必须真正修改导出像素，不得只给 `<img>` 添加 CSS filter 冒充编辑效果，也不得只展示不可用工具按钮。不接入后端、云存储、远程图片或在线图像处理 API。

## 一、工程结构与边界

1. 必须包含 package.json、index.html、src/main.tsx、src/App.tsx、README.md。
2. package.json 至少提供 `npm run dev`、`npm run build`、`npm run test`、`npm run typecheck` 或 `npm run lint`。
3. 核心编辑画布使用 Canvas 2D 或等价浏览器本地图形能力。允许轻量图形库，但坐标转换、裁切、滤镜参数、图层、历史和导出数据必须在项目中有可测试逻辑。
4. 不得用 CSS filter 冒充最终图像处理；导出的 PNG/JPEG 必须真实包含调整效果。
5. 不请求远程图片或 API Key 服务；不使用 dangerouslySetInnerHTML；不把完整页面或大段组件写成字符串模板。

## 二、界面布局与状态

桌面端布局：顶部导入/撤销/重做/对比/保存工程/导出；左侧工具栏（选择、裁切、调整、矩形、箭头、文字、画笔、马赛克）；中间棋盘格或中性背景上的可缩放画布；右侧工具参数、图层列表、图片信息；底部缩放比例、图片尺寸、光标坐标和当前状态。

必须有明显的当前工具、选中对象、编辑中、导出中、错误和未保存状态。360px 下工具栏可折叠，但导入、主要工具、图层、撤销/重做、导出仍可访问。

## 三、内置确定性示例图片

除了本地导入，必须提供“加载示例图片”。示例图片由 Canvas 或 SVG 在本地确定性生成，再转换为可编辑位图，至少包含：规则网格、红/绿/蓝/黄色块、人物或物体简化轮廓、带文字的路牌区域、左上角编号 A1、右下角编号 D4、明暗渐变、可验证方向的非对称元素。每次加载完全一致，不使用不可复现随机数。自动化测试应能用它验证旋转、翻转、裁切、滤镜和标注真实生效。

不得依赖评测者另行提供图片或工程文件；自动化测试所需的有效图片和损坏文件必须由项目代码或测试脚本确定性生成，工程 JSON 通过导出后再导入验证。

## 四、图片导入与生命周期

1. 支持点击或拖拽导入 PNG、JPEG、WebP。
2. 显示文件名、原始宽高、文件大小和格式。
3. 文件过大时给出提示但不白屏；解码失败、格式不支持或内容损坏时显示明确错误。
4. 更换图片前，如存在未保存编辑，提示确认。
5. 更换图片时释放旧 Object URL、ImageBitmap、临时 canvas 等资源。
6. 同一文件重复导入不叠加旧编辑状态。

## 五、编辑数据模型

应用必须区分：原始位图、非破坏性调整参数、裁切和方向变换、局部像素操作（如马赛克）、标注图层、编辑历史、导出配置。原始位图在 reset 前保持不变。预览和导出结果必须由同一份编辑状态渲染，不能出现预览有效但导出缺失的情况。

标注对象至少包含：id、type、x/y、width/height 或 points、rotation、stroke/fill、lineWidth、opacity、text/fontSize、visible、locked、zIndex。

## 六、画布导航与坐标系统

1. 支持放大、缩小、适应窗口和 100% 显示。
2. 支持空格临时手形或手形工具平移。
3. 缩放以鼠标位置或画布中心为锚点，交互稳定。
4. 屏幕坐标、画布坐标和图片原始像素坐标转换正确。
5. 任意缩放/平移状态下，裁切框、标注和鼠标命中位置仍准确。
6. 显示缩放比例、图片尺寸和光标对应的图片像素坐标。
7. 画布缩放/平移不改变最终导出尺寸或标注图片坐标。

## 七、裁切、旋转与翻转

裁切支持自由裁切、原始比例、1:1、4:3、16:9、3:4、自定义宽高比。裁切框可拖动和调四角/四边，不越出图片有效区域；显示裁切后像素尺寸；支持应用和取消，取消不修改图片。应用裁切后标注对象按明确规则转换到新图片坐标；裁切外标注可隐藏/裁剪/删除，但必须一致并在 README 说明。

旋转支持顺时针 90°、逆时针 90°、180°；翻转支持水平/垂直。90° 后图片宽高互换，图片和标注同步变换，不能只旋转底图或只旋转视觉容器。连续旋转四次 90° 后回到原始方向和尺寸。

## 八、全局调整与局部马赛克

至少支持 brightness、contrast、saturation、exposure 或 gamma、temperature、grayscale、sepia、blur、sharpen（可用确定性卷积近似）。参数有范围、默认值、重置单项和重置全部。拖动参数时预览实时更新，但避免每个指针事件全尺寸重算；调整必须影响真实导出像素；相同图片和参数得到相同结果。

局部马赛克：用户拖出矩形区域，马赛克真实影响导出像素而非覆盖半透明矩形；可调块大小；区域移动/缩放后结果同步更新；该操作进入历史。

## 九、标注工具

至少支持：

1. 矩形：拖动创建，可调整大小，设置描边/填充/透明度/线宽。
2. 箭头：拖动起点终点，箭头头部方向正确，可调颜色/线宽。
3. 文字：点击创建，可编辑文本、字号、颜色和背景；空文字不能保留为无意义图层；编辑文字时快捷键不误触画布工具。
4. 自由画笔：记录连续路径，支持颜色、线宽、透明度；指针移出或取消时不留下损坏路径。
5. 局部马赛克：作为像素操作或图层化区域参与渲染和导出。

## 十、选择、命中与图层管理

1. 选择工具点击最上层可命中对象；正确处理重叠和 zIndex。
2. 选中对象显示边界框和控制点，支持移动、缩放和删除。
3. 图层面板按前后顺序显示对象，支持上移、下移、置顶、置底。
4. 支持显示/隐藏和锁定/解锁；锁定对象不能被画布拖动或删除；隐藏对象不出现在画布和最终导出中。
5. 删除选中对象后选择状态清空。

## 十一、撤销、重做、重置和对比

以下操作进入统一历史：添加/移动/缩放/删除标注、图层顺序和可见性、应用裁切、旋转/翻转、调整参数、马赛克。支持工具栏按钮和 Cmd/Ctrl+Z、Cmd/Ctrl+Shift+Z。新操作后清除 redo 分支。连续滑杆拖动应在结束时合并为一个历史点。重置图片前确认；重置后回到刚导入状态，历史、标注、裁切、滤镜和选择清空。

提供真实前后对比：按住显示原图、左右分屏或可拖动滑杆均可。对比必须使用原始位图与当前完整编辑结果，不能只关闭 CSS 效果；退出对比后当前状态不丢失。

## 十二、保存、恢复与导出

1. 编辑状态保存到 IndexedDB，包括图片 Blob 或可恢复引用、调整参数、裁切、方向、标注、历史摘要。
2. 刷新后提示恢复上次工程或丢弃；坏值、旧版本或缺字段不能白屏。
3. 支持导出工程 JSON；如 JSON 不内嵌原图，需记录原图名称、宽高、校验信息，并在重新导入时提示选择原图。
4. 导入工程后，画布、滤镜、裁切和标注恢复。
5. 支持导出 PNG 和 JPEG，能选择是否包含标注、背景色、质量或尺寸倍率。
6. 导出结果真实包含裁切、旋转、翻转、滤镜、马赛克和可见标注；隐藏图层不导出。
7. 导出中显示状态，失败有错误提示，重复导出不造成状态错乱。

## 十三、响应式与可访问性

1. 360px 下可导入/加载示例、选择工具、编辑参数、查看图层、撤销/重做和导出。
2. 所有工具和输入有 label 或 aria-label；focus 清晰；错误、选中、禁用状态不能只靠颜色。
3. reduced-motion 下减少非必要动画，不影响编辑状态。
