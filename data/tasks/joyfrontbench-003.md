一级分类：网页 / 业务界面
二级分类：官网界面

你是一名世界顶级的前端设计与开发专家。请为 **iPhone** 打造一个高端、可交互的品牌产品官网，并最终交付一个**完整、可直接运行的单 HTML 文件**（可直接保存为 `.html` 双击在浏览器打开，无需任何后端、无需联网、无需构建工具）。

本题不接入任何真实后端，所有产品数据均使用内置的模拟数据（mock data）。

### 一、总体定位与视觉基调

1. 整体是一个单页官网（Single Page），通过顶部导航锚点在同一页面内的多个区块之间平滑滚动跳转。
2. 视觉必须是高端的 Apple 官网气质：大面积留白、克制的配色、清晰的视觉层级、精致的排版。字体要有设计感和独特性，**不要使用系统默认字体的平庸观感**，可通过 `font-family` 组合、字重与字距营造高级感。
3. 坚决拒绝一眼假的「通用 AI 生成风格」。配色与布局要有惊喜感，但保持克制与统一。
4. 不允许使用外部图片资源或 3D 模型文件。产品外观、图标、装饰图形等**一律用纯 CSS / SVG / Canvas 代码绘制**，力求精致。

### 二、页面结构（区块）

页面自上而下至少包含以下区块，均可通过导航栏锚点跳转：

1. **顶部导航栏（Header / Nav）**：品牌 Logo（代码绘制）、栏目锚点（如「概览 / 画廊 / 规格 / 购买」）。滚动时导航栏有毛玻璃/收缩等状态变化。
2. **首屏 Hero 区**：主打机型的大标题、卖点副文案、代码绘制的 iPhone 主视觉，以及「了解更多 / 立即购买」按钮。
3. **产品画廊 / 媒体展示区**：展示 iPhone 的多角度或多颜色形态，支持颜色切换后主视觉**实时更新**。
4. **交互体验区（原题核心）**：一处随手指滑动 / 鼠标拖动 / 滚动而**实时、平滑、生动变化**的图形动画（纯代码绘制的图形或线条），体现流畅的实时反馈。
5. **规格 / 机型对比区**：以对比表或对比卡片形式，展示不同机型的关键规格差异（屏幕、芯片、摄像头、价格等）。
6. **购买区（Buy）**：机型 / 容量 / 颜色选配器，随选择实时计算并展示价格。
7. **页脚（Footer）**：栏目分组链接、版权信息等。

内置以下 3 款机型，字段包含机型名、可选容量及对应价格、可选颜色、关键规格：

| iPhone 17 | 128GB ¥5999 / 256GB ¥6999 / 512GB ¥8999 | 黑色、白色、粉色、海蓝、松绿 | A19 | 6.1″ | 4800万双摄 |

### 四、核心功能要求

#### 1. 全代码绘制视觉
- iPhone 主视觉、品牌 Logo、图标、装饰图形等一律用 CSS / SVG / Canvas 绘制，不引用任何外部图片或 3D 模型文件。

#### 2. 产品画廊 / 媒体展示
- 以精致的方式展示 iPhone 的多角度或多颜色形态，切换时有平滑过渡。

#### 3. 颜色 / 容量选配的动态渲染
- 在购买区与画廊区，切换颜色后产品主视觉机身配色**实时更新**；切换机型 / 容量后价格**实时重算并展示**；不出现「数据变了但界面没变」的问题。

#### 4. 交互与滚动体验
- 顶部导航锚点点击后平滑滚动到对应区块；滚动时导航栏状态、区块入场动画等有合理反馈。
- 交互体验区的图形动画需随用户输入（滑动/拖动/滚动）**实时、平滑**变化，不卡顿、不突兀。

#### 5. 组件完整性
- 导航栏、按钮、产品卡片、对比表、选配器、页脚等组件齐全；各交互入口均可点击，有 hover / active 等状态反馈。

#### 6. 美观一致性
- 各组件视觉风格统一；页面在主流桌面分辨率下无严重错位，窄屏（移动端宽度）下仍可基本使用；信息密度合理。

### 五、技术与交付约束

1. 交付**单个 HTML 文件**，所有 HTML / CSS / JS 内联其中，可直接双击运行，不依赖任何外部资源、网络或构建工具。
2. 不接入真实后端；产品数据均使用内置 mock 数据。
3. 不允许出现引用未定义函数 / 未定义变量导致的运行报错；控制台不应有阻断功能的报错。
4. 所有状态变更必须正确驱动界面更新。
