一级分类：应用
二级分类：复古 RPG/回合制游戏

你是一名顶尖的游戏开发专家。请制作一个**超复古的网页小游戏**，风格要**完全神似当年掌机上的黑白像素「宝可梦」类捕怪 RPG**，游戏名叫 **"Creature Catcher"**。所有代码、逻辑与美术**全部放进一个 HTML 文件**，可直接拖进浏览器立即游玩（无需后端、无需构建工具）。**请勿使用任何有版权的素材**——怪物、地图、美术均需你原创、通用化设计。

### 一、探索地图

1. **网格步进移动**：一切以格子为单位**逐格移动**，像老掌机那样一步一步走，而非平滑滑动。
2. **像素观感**：屏幕看起来大，但实为**低分辨率、明显的像素颗粒感**，仅用**简单的 4-bit 色板**（复古黑白/低色）。
3. **可探索的初始地图**：包含一栋**可以真正走进走出的小房子**（进出触发场景切换），以及一片**高草丛**——走进草丛会随机遇到野生怪物。
4. **走路动画**：角色行走时有**可爱的迈步动画**（行走帧），而非整体滑动。

### 二、战斗系统

1. **遇敌转场**：在草丛撞见怪物时，屏幕先播放一个**帅气的转场特效**，再切入战斗画面。
2. **战斗布局**：己方怪物**背对玩家**、敌方怪物**面向玩家**；双方均显示**名字、等级、血条**。
3. **底部指令菜单**：底部菜单需**真正可用**，包含 **FIGHT / MON / ITEM / RUN** 四项，各有实际功能。
4. **回合叙事与动画**：回合发生的事件以**底部文字框逐条弹出**叙述（谁攻击了谁等剧情），并配有**攻击命中动画**与**血条增减的动画**。
5. **胜负结算**：战斗结束后正确结算并返回探索地图。

### 三、菜单与控制

1. **控制方案**（固定）：**WASD 移动**；**J = "A" 键**（确认）；**K = "B" 键**（取消/返回）；**L 打开开始菜单**。
2. **开始菜单**：包含 **DEX（图鉴）/ PARTY（队伍）/ ITEM（道具）/ OPTION（设置）/ EXIT** 五项，**每一项都要真正能用**：
   - DEX：可查看已遇到/捕获的怪物图鉴记录；
   - PARTY：查看与管理己方队伍怪物（HP、等级等）；
   - ITEM：查看与使用道具；
   - OPTION：可调整设置项（如文字速度、音效开关等）并即时生效；
   - EXIT：关闭菜单返回游戏。

### 四、数据与存档

1. **队伍 / 道具 / 图鉴**：捕获怪物加入队伍、使用道具后数量与效果正确变化、遇见/捕获的怪物计入图鉴——这些数据在探索与战斗中保持一致。
2. **存档系统**：支持**存档 / 读档**，进度使用 `localStorage` 持久化（刷新或重开浏览器后可继续）；并支持将存档**导出为文件**、以及**从文件导入**存档以恢复进度。
3. 不得依赖预先提供的存档文件；你必须让实现或自动化测试从确定性游戏状态自行导出合法存档，再导入同一文件验证恢复。

### 五、核心功能要求

1. 网格逐格移动、行走帧动画、WASD+JKL 控制方案正确。
2. 地图探索与场景切换：房子可进出、草丛触发遇敌，地图状态正确切换。
3. 遇敌转场 + 战斗界面布局（己方背对/敌方面向、名字等级血条）+ 命中/血条动画。
4. 战斗回合闭环：FIGHT/MON/ITEM/RUN 全可用、底部文字框逐条叙事、回合推进、胜负结算返回地图。
5. 开始菜单 DEX/PARTY/ITEM/OPTION/EXIT 五项均有实际功能。
6. 队伍/道具/图鉴的增删改查在各界面间数据一致。
7. 存档：SAVE/读档 localStorage 持久化，存档可导出/导入为文件。
8. 复古 4-bit 像素美术与低分辨率观感，画面统一有复古美感。

### 六、技术与交付约束

1. 交付**单个 HTML 文件**，全部代码/逻辑/美术内联，拖入浏览器即玩，无需后端与构建工具。
2. 全部美术为原创、通用化设计，不含任何有版权素材。
3. 状态变更（移动、战斗、菜单、队伍/道具/图鉴、存档）需正确驱动画面与 UI 更新；控制台无阻断性报错。
