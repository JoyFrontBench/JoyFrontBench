一级分类：SVG / 矢量图形生成
二级分类：静态 SVG 插画/场景

扮演资深 SVG 动效工程师，用纯内联 SVG 制作"一只章鱼演奏整套架子鼓"的
    循环动画，交付单个可离线双击运行的 .html 文件。第一眼要能认出这是一只
    八爪章鱼在真正地打一套完整爵士鼓，而不是随意堆放的图形。

    【整体场景】
    1. 构建一个可信的演出环境：一块有厚度与透视的鼓台/舞台地面，鼓组稳稳
       立在其上；背景有明确氛围（如深海舞台或小型 Live 现场），可用聚光、
       光晕、层次色调营造纵深，但不得喧宾夺主或遮挡鼓手动作。
    2. 章鱼、鼓组、舞台、灯光需有合理的前后遮挡与层次，构图平衡、居中突出。

    【章鱼与分工】
    3. 章鱼含躯干、头部与 8 条可辨识、姿态自然的腕足，且必须明确分工：
       一部分腕足各握鼓槌敲击鼓面/镲面，另一部分腕足向下踩住并操作脚踏
       （低音大鼓踏板与踩镲踏板）。握槌与踩踏的腕足都不得空闲或重叠挤向同处。

    【鼓组】
    4. 完整鼓组：带脚踏的低音大鼓、军鼓、落地嗵鼓、两个吊嗵鼓、踩镲、
       吊镲、节奏镲，布局与层次符合真实鼓手视角。

    【动画与联动】
    5. 用 SMIL 或 CSS 驱动一段 2–4 秒、可无缝循环的鼓点，各腕足节奏有差异
       （镲点密集、大鼓沉稳）。
    6. 握槌腕足敲击时，槌头必须真正落到对应鼓面/镲面再回弹；踩踏腕足下压时，
       必须联动对应机构——大鼓踏板下压使鼓槌击中鼓面、踩镲踏板下压使上下
       镲片合拢。全周期不得穿模、错位或悬空脱离目标。

    【约束】
    7. 所有图形由 SVG 原生元素绘制；背景氛围可用内联 CSS，但鼓组、章鱼与
       核心细节必须是 SVG。禁止外部图片、Canvas、WebGL、CDN、iframe、网络
       请求；连续运动必须由 SMIL/CSS 驱动，不得用逐帧 JS 替代。请你完成这个任务
