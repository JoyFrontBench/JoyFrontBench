二级分类：时序动画演示

请使用 **Three.js 编写一个单文件 HTML/JS 交互演示**，模拟一颗被加热至橙红色的金属球落入盛有液氮的透明开放式杜瓦容器中，完整展示：**释放 → 入液冲击 → 膜态沸腾 → 蒸气膜失稳 → 核态沸腾 → 金属冷却 → 低温雾沿桌面扩散** 的全过程。

这是一个科学可视化演示，不要求严格 CFD 求解器，但必须体现清晰的物理因果链：所有主要视觉状态应由 **金属温度、速度、浸没深度、蒸气膜稳定度、蒸气生成率、液面高度 / 液氮液位** 等连续变量驱动，而不是依靠写死关键帧、阶段文字切换或突然显示 / 隐藏对象来制造效果。

## 物理核心与科学边界

- 液氮本身近乎无色透明，液体可呈极淡青色；容器外的白色低温雾是空气中水蒸气遇冷凝结形成的微小液滴，**不是氮气本身有颜色**。
- 高温金属球刚接触液氮时，液氮快速汽化，在球体表面形成隔热蒸气膜，即 **膜态沸腾 / Leidenfrost 状态**。
- 随着金属球降温，蒸气膜逐渐变薄、波动、局部破裂，液氮开始间歇接触金属表面。
- 蒸气膜大范围瓦解后转入 **核态沸腾**：球体表面出现大量细密成核点和密集上升气泡。
- 温差继续降低后，沸腾强度衰减，球体恢复暗灰金属色，液面、气泡和冷雾逐渐趋于平静。
- 状态转换应由温差和蒸气膜稳定度决定，并加入少量迟滞，避免高频闪烁。

## 场景与材质要求

### 实验室环境

- 场景是明亮、洁净的低温物理实验室；浅灰实验台具有微弱反射。
- 使用 **ACES Filmic Tone Mapping**、合适曝光和适量 Bloom；Bloom 主要服务于高温金属球、入液瞬间蒸气团和发光衰减，不得让全屏过曝。
- 可使用程序化 Canvas / CubeTexture 环境贴图或由代码生成的环境反射；不得额外下载 HDR / 图片资源。

### 开放式双层玻璃杜瓦容器

- 杜瓦容器必须可被一眼识别为透明开放容器，而不是普通杯子：包含 **内壁、外壁、夹层、厚底、圆滑杯口**。
- 使用带 transmission、IOR、thickness、roughness、attenuation 等参数的 `MeshPhysicalMaterial` 或等价 PBR 玻璃材质表现透明厚玻璃。
- 容器顶部开放，液氮约填充到 **70% 高度**；液氮近乎透明、略带淡青色。
- 容器与液体有合理遮挡关系：球入液后应能透过玻璃和液氮看到球、气泡、蒸气膜和液面扰动。

### 液面与液氮

- 液面使用可变形网格（规则高度场或简化波动方程），实时更新顶点和法线。
- 液面要响应：球体撞击凹坑、环形液冠、涟漪传播、气泡破裂、持续沸腾和液滴回落。
- 液氮液位因汽化略微下降；该下降应随蒸气生成率积分而变化，而非固定阶段跳变。

### 高温金属球

- 金属球直径约为容器内径的 1/4，默认初温 **850°C**，可调范围为 **600–1000°C**。
- 球体颜色随温度连续经历 **橙黄 → 红色 → 暗红 → 灰黑金属色**；自发光、Bloom 和局部点光强度随温度同步衰减。
- 使用金属 PBR 材质，降温后恢复暗灰金属表面；不得只通过贴图或几帧颜色关键帧假装冷却。

## 简化物理模型

实现可简化，但需要有可读的状态变量、更新函数和相互耦合关系。

### 金属球运动

- 点击「开始实验」后夹具松开，金属球受重力下落。
- 入液后运动受以下因素影响：重力、浸没比例相关的浮力、液体二次阻力，以及蒸气喷发产生的轻微脉冲力和力矩。
- 入液后速度应明显下降，球体缓慢沉向容器下部，不应直线穿过液体或瞬移到底部。

### 热模型

- 使用集中热容模型，保存质量、比热容、表面积、温度、液氮沸点和温差。
- 不同沸腾状态使用不同有效换热系数：膜态沸腾换热相对弱，蒸气膜失稳后增强，核态沸腾最强，末期随温差降低衰减。
- 温度应连续下降；初始温度越高，沸腾持续时间和强度越大。

### 蒸气膜

- 蒸气膜保存平均厚度、局部扰动、稳定度和破裂比例。
- 膜态沸腾时，球体外应包裹连续但不均匀的半透明蒸气膜；膜厚持续波动，出现鼓包、收缩和沿球面流动。
- 蒸气膜失稳时，膜必须连续变薄并局部塌陷，不能直接隐藏。

### 气泡、液滴与冷雾

- 气泡保存位置、速度、半径、年龄、摇摆相位和蒸气浓度，模拟浮力、阻力、膨胀、分裂 / 合并与液面破裂。
- 气泡形态应从膜态沸腾的大而稀疏，逐渐过渡为核态沸腾的小而密集。
- 液滴可用对象池模拟入液冲击和沸腾飞溅。
- 冷雾使用分层粒子模拟密度较大的贴地重力流：越过杯口后向下沉降，并沿实验台扩散、绕过容器、随时间变薄消散，不得像热烟一样持续向上飘。

## 动画阶段

### 1. 释放与入液

- 初始状态显示夹具固定高温金属球，完整实验场景已加载但不自动开始。
- 点击「开始实验」后夹具松开，球体受重力下落。
- 接触液面时形成凹坑、环形液冠、连续液膜、飞溅液滴和向外传播的涟漪。
- 初始汽化产生短暂高亮蒸气团；球入液后明显受阻并缓慢下沉。

### 2. 膜态沸腾

- 球体外包裹连续但不均匀的半透明蒸气膜。
- 蒸气膜厚度持续波动，出现局部鼓包、收缩和沿球面流动。
- 蒸气在球体顶部脱离成较大的不规则气泡；气泡摇摆上升、略微膨胀，并可分裂或合并。
- 气泡到达液面后造成隆起、破裂、涟漪和少量冷雾。

### 3. 蒸气膜失稳

- 蒸气膜连续变薄，局部塌陷和破裂面积逐渐增加。
- 液氮间歇接触球体表面，每次接触产生短促蒸气喷发。
- 喷发位置沿球面迁移，并对球体施加轻微脉冲力和力矩，使球体出现细小抖动 / 转动。
- 气泡形态由大而稀疏逐渐变为小而密集。

### 4. 核态沸腾

- 球体表面同时出现大量细小成核点，形成密集气泡羽流。
- 液面剧烈翻滚、鼓起和飞溅，容器口上方出现浓密白雾。
- 冷雾越过杯口后向下沉降，并沿实验台贴地扩散。
- 容器外壁逐渐出现冷凝水和少量霜状痕迹。

### 5. 冷却沉寂

- 金属球恢复暗灰金属色，自发光和局部点光衰减到接近 0。
- 气泡生成率持续降低，液面波动逐渐衰减，液位略低于初始高度。
- 剩余冷雾沿桌面扩散、变薄并消散，最后只剩零星气泡。

## 人工选择实验进度（必须实现）

控制面板必须提供一个 **0%–100% 的「实验进度」滑块**，用户可以在实验开始前、播放中或暂停时任意拖动。

- 进度至少映射到五个明确区间：**释放与入液、膜态沸腾、蒸气膜失稳、核态沸腾、冷却沉寂**。
- 用户拖动滑块后，演示应立即暂停在对应时刻，主按钮显示「继续」，方便观察。
- 跳转不能只更改阶段文字或显示 / 隐藏特效，必须同步重建：金属球位置、速度、温度、颜色、发光强度、蒸气膜厚度、气泡数量和尺寸、液面扰动、液氮液位、冷雾密度以及时间读数。
- 进度条必须双向同步：自动播放时滑块随模拟推进；人工拖动时底部时间线和实时数据面板立即更新。
- 0% 恢复到释放前状态；100% 显示实验结束后的低温金属球、下降液位和残余冷雾。
- 人工跳转后不得出现上一个阶段残留的大量粒子、错误温度或球体瞬移回初始位置。
- 底部「实验进程」时间线也必须可直接拖动，并与控制面板中的 0%–100% 滑块双向同步。
- 底部五个阶段名称必须是可点击控件；点击「释放」「膜态沸腾」「蒸气膜失稳」「核态沸腾」或「冷却沉寂」后，应跳转到该阶段代表性进度并暂停观察。
- 可交互时间线必须具有明确的悬停、焦点和当前阶段视觉反馈，不能把普通文本伪装成可点击元素。
- 从任意人工选择的进度点击「继续」，模拟都应从当前状态稳定接续。

## 交互控制

- **开始实验 / 暂停 / 继续：** 点击开始释放金属球；播放中可暂停；拖动进度后按钮应显示「继续」并从当前状态恢复。
- **重置：** 恢复到释放前状态，清空粒子残留、恢复默认时间读数和液位，允许重新实验。
- **时间倍率：** 提供 0.1x–1.0x 时间倍率控制，改变模拟推进速度但不改变物理状态映射。
- **初始温度：** 提供 600–1000°C 初始温度滑块；初始温度应影响沸腾持续时间、气泡生成率、冷雾密度和最终冷却曲线。
- **实验进度：** 提供 0%–100% 滑块，满足上一节的双向同步和暂停观察要求。
- **视角切换：** 至少四个预设视角：**实验台全景、容器侧面近景、液面下仰视、金属球微距**。切换视角不应重置模拟。
- **OrbitControls：** 支持自由旋转和缩放，可与预设视角共存。

## 数据面板与可观察状态

常驻数据面板实时显示：

- 实验时间；
- 金属球温度；
- 当前沸腾状态；
- 蒸气膜厚度；
- 蒸气生成率 / 气泡生成率；
- 液氮液位；
- 当前实验进度百分比。

这些数值必须由同一份模拟状态驱动，并与画面一致：例如温度降低时球体辉光下降，膜厚降低时膜变薄，气泡生成率升高时气泡数量和液面扰动增强，液位随累计汽化略微下降。

## 性能与代码要求

- 所有 HTML、CSS 和 JavaScript 封装在一个 HTML 文件中；Three.js 可通过 CDN 以 ES Module 加载。
- 不引入外部物理引擎。
- 使用清晰的类或模块管理：热模型、液面、蒸气膜、气泡、液滴、冷雾、相机、UI 和实验进度重建。
- 气泡、液滴和冷雾使用 `InstancedMesh`、`Points` 或对象池，动画循环中避免频繁创建与销毁对象。
- 高温照明复用固定 `PointLight`，主要使用 emissive 材质和 Bloom 表现温度辉光。
- 支持窗口缩放和任意时刻重置；页面加载后先显示完整初始场景。约 360px 宽屏幕下，开始按钮和进度条仍可操作，数据面板可读或可展开查看，面板不得遮挡杜瓦口和金属球。
- 控制台不应出现运行时报错、资源 404 或 Three.js dispose / resize 后访问错误。
