一级分类：应用
二级分类：3D 游戏

请用 **Three.js** 实现一个**单文件**的 3D 小游戏原型：一个 cel-shaded（卡通渲染）风格的「**Tiny Planet（小小星球）**」游戏，玩法上有点像"球面版吃豆人"。最终交付一个**可直接运行的 HTML 文件**（可通过 CDN 引入或内联 Three.js，在浏览器中打开即可游玩，无需构建工具）。

### 一、核心场景与机制

1. **星球环境**：环境是一个**大球体星球**，配有柔和的**大气雾（atmospheric fog）**营造氛围；整体采用 cel-shaded 卡通渲染风格（明快色块 + 描边感）。
2. **球心重力**：重力**始终指向星球中心**，角色能贴着球面**行走遍历整个星球表面**，无论走到球的哪个位置都"脚踩地面、头朝外"，姿态随球面朝向自然对齐，不会飞出或穿入球体。
3. **操控**：使用标准 **WASD 移动 + 空格跳跃**；角色在曲面上按输入方向平滑移动。
4. **相机**：相机**紧贴并跟随角色**（近距离、第三人称），带来沉浸感而非远距俯瞰；相机随角色在球面上的移动与朝向平滑跟随，不翻转、不穿模。
5. **玩法循环**：星球表面散布**金色圆环**供玩家收集计分；同时有**怪物在球面上追逐玩家**；所有对象（角色、怪物、金环、地面）之间需有**可靠的碰撞检测**（收集金环、被怪物抓到、跳跃落地）。

### 二、游戏流程与状态闭环

在核心玩法之外，需构成一个完整可玩的游戏闭环：

1. **开始界面**：进入游戏先展示开始菜单，玩家可**输入昵称**后开始游戏（昵称用于计入排行榜）。
2. **游戏进行**：HUD 实时显示当前得分、剩余金环数量（或已收集数）等信息；收集金环时得分增加、该金环从星球上移除。
3. **结束条件**：被怪物抓到（或达成收集目标）时游戏结束，弹出结算，展示本局得分。
4. **本地排行榜**：结算后将「昵称 + 得分」写入排行榜并按分数排序展示；排行榜使用 `localStorage` 持久化（刷新后仍在），并支持清空榜单。
5. **重新开始**：可从结算界面一键重开新的一局，状态正确重置（分数归零、金环与怪物重置、角色回到初始位置）。

### 三、核心功能要求

1. **球心重力与角色贴合**：重力恒指向球心，角色可遍历整个球面且始终贴合表面、姿态对齐球面法线，不飞出/不穿模。
2. **球面移动操控**：WASD 在曲面上按输入方向平滑移动，空格跳跃后受球心重力回落到球面。
3. **相机紧贴跟随**：第三人称近景相机平滑跟随角色，随球面移动/朝向变化而不翻转、不穿模、不抖动。
4. **怪物球面 AI 追逐**：怪物同样贴合球面并沿球面朝玩家方向追逐移动，行为合理、不脱离球面。
5. **碰撞检测**：金环收集、怪物抓到玩家、跳跃落地等碰撞判定可靠、无穿透或漏判。
6. **游戏状态与闭环**：开始→进行→结束→重开的完整循环；计分正确；重开时状态完全重置。
7. **昵称表单与本地排行榜**：开始前可输入昵称；结束后昵称+得分入榜、排序展示、`localStorage` 持久化、可清空。
8. **视觉风格**：cel-shaded 卡通渲染 + 大气雾，画面统一、有美感。

### 四、技术与交付约束

1. 交付**单个 HTML 文件**，可通过 CDN 引入或将 Three.js 内联；在浏览器中打开即可游玩，无需后端与构建工具。
2. 帧率稳定、实时响应输入；控制台无阻断性报错。
3. 所有游戏状态变更（得分、金环增减、游戏开始/结束、排行榜）需正确驱动画面与 UI 更新。
